# Self-preference score artifacts

These files apply the legacy estimands in Sections 3.1–3.3 of
`docs/archive/legacy_manuscript.md` to the retained completed experiment
records. Standalone judging-pilot conditions are excluded; early batches of the
same combined condition are retained as part of the completed run. The current
interpretation of these secondary measures is in `docs/experiment.md`.
They are generated by:

```bash
uv run python scripts/create_self_preference_scores.py
```

## Score definitions

For model `j`, answer `j`, and question `q`, the generalized rubric score is:

```text
rubric_sp_bias = own judge's mean five-axis score
                 - mean score from all outside judges for the same answer
```

Positive values mean own-judge score inflation; negative values mean
self-criticism. The pairwise file uses one outside judge at a time, exactly
matching the first draft's original SP-Bias comparison. Overall rubric scores
are means, so this remains on the source 0–5 scale even though the expanded
rubric axes differ from the legacy axes.

The matched rank sensitivity is:

```text
rank_effect = own judge's rank for its answer
              - mean rank from all outside judges for the same answer
```

Negative values mean self-preference because lower ranks are better. These
values are unadjusted to remain a transparent application of the original
method; the paper's primary position-adjusted rank analysis remains in
`scripts/analyze_new_self_preference.py`.

The decision measure converts each strict listwise ranking into all head-to-head
decisions involving the judge's own answer:

```text
own_pick_rate = times own judge ranks own answer above a competitor
                / all own-answer-versus-competitor comparisons
```

The saved rankings contain no ties. Pairwise p-values are exact two-sided
binomial tests against 0.5. Model-level p-values pool multiple correlated
competitors and are therefore descriptive; use model-vs-model rows for the
closest analogue of the first draft's inferential test. Wilson 95% intervals
are supplied for proportions. `binomial_log10_p` preserves extremely small
values when `binomial_p` underflows to zero.

## Files

- `model_scores.csv`: one row per dataset/condition/model, including mean
  SP-Bias, paired t interval and p-value, matched rank effect, and own-pick rate.
- `pairwise_scores.csv`: every directional model-vs-outside-model comparison.
- `question_model_scores.csv`: the question-level values underlying model
  summaries and paired inference.
- `manifest.json`: experiment IDs, deduplicated record counts, source hashes,
  output row counts, and output hashes.
- `token_length_analysis.json`: fixed-effects response-length associations for
  model scoring and within-model moderation of matched self-preference.
- `token_length_model_summary.csv`: model-level lexical-token lengths and
  descriptive mean ranks/scores standardized to the pooled mean length.
- `medsp1000_all_eight_judges_v2.json`: position-adjusted matched effects for
  the complete eight-model MedSP1000 extension, including repeated-measures
  transcript-length tests.

The eight-model MedSP1000 analysis is generated with:

```bash
uv run python scripts/analyze_new_self_preference.py \
  --medsp-experiment-id medsp1000_all_eight_judges_v2 \
  --output data/analysis/self_preference/medsp1000_all_eight_judges_v2.json
```

The token-length files are generated separately with:

```bash
uv run python scripts/analyze_token_length_confounding.py
```

They use a common lexical tokenizer on the exact answer text because provider
usage tokens are not directly comparable across model families. Provider-token
analyses are included as a directional sensitivity check.

Append-only judgment files are deduplicated by `(question_id, judge_model)`,
retaining the last successful attempt for each production experiment ID.

The identity-revealed Real-POCQi condition contains six API judges but eight
candidate generators. Its model summaries therefore average score/rank
contrasts over five outside judges while decision rates compare the own answer
against all seven competing generators. In `pairwise_scores.csv`, Qwen-opponent
rows for that condition contain decision results but blank rubric/rank
contrasts because Qwen did not serve as an identity-revealed judge.
